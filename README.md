# Smart Sales Analytics Dashboard

An interactive sales analytics dashboard built with Python and Streamlit. This project analyzes sales data and presents useful business insights through charts, and product analysis.

## Features
- Total Sales
- Total Quantity Sold
- Average Sale
- Best-Selling Product
- Top Products by Sales
- Monthly Sales Analysis
- Interactive charts and visualizations
- CSV dataset support
- Simple and user-friendly dashboard

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Dataset
This project uses a CSV sales dataset containing information such as products, sales amounts, quantities, and dates. Pandas is used to load, clean, process, and analyze the dataset.

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn streamlit`
4. Run the application:
   `streamlit run app.py`
5. The dashboard will open in your web browser.
